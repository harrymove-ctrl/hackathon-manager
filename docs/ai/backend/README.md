# Backend Subsystem

## What
Express.js TypeScript server exposing REST endpoints for hackathon resources, deadlines, tasks, squad progress, and PostgreSQL database observability.

## Areas
- [`routes.md`](./routes.md) — REST API endpoints for resources, deadlines, tasks, and team.
- [`database.md`](./database.md) — Prisma client, data models, and official BNB Chain seed data.
- [`pgbot.md`](./pgbot.md) — Real-time database telemetry and PostgreSQL statistics profiler.
