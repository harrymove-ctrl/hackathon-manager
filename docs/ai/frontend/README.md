# Frontend Subsystem

## What
Client-side Single Page Application providing a retro-futuristic `term-v0` command interface with multi-palette styling, responsive tracks matrix, and live radio browser.

## Areas
- [`tui-app.md`](./tui-app.md) — Application core, view switcher, theme palette engine, and API client.
- [`radio.md`](./radio.md) — Radio Browser integration and canvas oscilloscope audio visualizer.
