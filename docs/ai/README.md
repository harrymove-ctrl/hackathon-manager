# AI Navigation

This repository is the **BNB Chain Smart Money Era Hackathon Manager & Observability Terminal**, implementing a retro-futuristic `term-v0` web interface, REST API, Prisma PostgreSQL backend, and pgbot database telemetry profiler.

## Codebase Map

- [`backend/`](./backend/) — Express.js TypeScript API server, Prisma ORM models, routes, and pgbot profiler.
- [`frontend/`](./frontend/) — term-v0 single-page terminal application, retro CSS design tokens, and live radio browser.
- [`devops/`](./devops/) — Railway deployment configuration, start scripts, and database lifecycle management.
